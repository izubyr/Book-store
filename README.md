# 📚 Marginalia Booksellers

A vintage, editorial storefront landing page for an independent antiquarian bookseller, crafted with semantic HTML5 and styled using the modern Tailwind CSS v4 CLI engine.

---

## 📖 Overview

**Marginalia Booksellers** is a curated digital catalog for rare editions, first printings, and out-of-print literary curiosities. The design mirrors traditional print typography—combining warm parchment paper tones, speckled leather accents, serif headlines, and monospace catalog metadata inspired by traditional book trade bulletins.

### 🌟 Key Features
- **Editorial Typography Stack:** Layered combination of `EB Garamond` for headings, `Literata` for editorial body copy, and `Courier Prime` for catalog numbers and archival classifications.
- **Acquisition of the Week:** Featured spotlight card showcasing provenance notes, edition details, and pricing[cite: 37].
- **Hand-Cataloged Gallery:** Responsive multi-column grid displaying rare books, custom condition tags (*First Edition*, *First Printing*, *Slipcase*), and quick "+ Basket" interactions[cite: 37].
- **Curated Sections:** Dedicated layouts for Antiquarian Standards, Desiderata / Book Hunter title request services, and a newsletter dispatch signup[cite: 37].
- **Tailwind CSS v4 Build Pipeline:** Built using Tailwind's standalone `@tailwindcss/cli` engine with minimal dependencies and fast rebuilds[cite: 38].

---

##🛠️ Built With
- **HTML5** Semantic architecture (<header>, <nav>, <section>, <footer>) with inline SVG favicons and accessibility landmarks
- **Tailwind CSS** Utility-first styling utilizing arbitrary font declarations, fluid grid columns, custom border accents, and color palettes
